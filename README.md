# FoolsIron

瞑想・入眠のためのドローン／ノイズ／合成音声機械。鳴らして、置いておく生成器である。
名は David Rosenboom《Portable Gold and Philosophers' Stones》への敬意による。

Android と Windows の双方で動くよう、依存なしの単一ページ（WebAudio / AudioWorklet）とする。
GitHub Pages で配る： https://whawhawhawhat.github.io/foolsiron/

## 発音部

| 部 | 中身 |
|---|---|
| 持続音 | 基音の16倍音までの格子。各倍音は二声のうなりを持ち、非周期の揺らぎで明滅する。副発振つき |
| ノイズ | 非楽音の部。地の雑音（白・桃・茶）に、物理由来の事象を重ねる：粒子（ぶつかる粒。雨、砂利、焚火）、泡（水中の気泡。雫、せせらぎ）、軋み（貼り付いては滑る摩擦）。荒れ・ハム・クラッシュ、共振フィルター（発振可）、帰還路、歪みで加工する |
| 共鳴 | 音階に調律した16の共鳴器。雑音・反復・声が共有して鳴らす |
| 反復 | オクターブ積層の声部（シェパード音）。アルペジオ／グリッサンド（Risset グリッサンド）／ループ（非通約ループ）の三モード |
| 声 | 声道の物理モデル（Kelly-Lochbaum）による、意味の取れぬ発話。声門の音源を区間に刻んだ管に通し、舌と唇で断面を動かす。種ごとに語彙を持つ架空の言語を喋る。囁き、詠唱も可 |
| 笛 | 管の物理モデル。数音を吹いて長く黙る。エアリード（フルート、尺八）からリード（警笛）まで。息の圧が足りなければ息だけが漏れる |
| 鐘 | モーダル合成。数打して長く黙る。棒・椀・洋鐘・梵鐘・板の振動の型を材質で渡る |
| 場 | 八本の遅延線による残響、全体の広がりと漂い、LFO 二基 |
| FX | フェイザー（ドローンとノイズ）、テープエコー（各部に送り）、ダブ卓の自動演奏（消し・放り込み・低域の掃引・帰還の煽り） |

## 操作

画面は正方形の一枚に収めてある。上辺のタブで面を切り替える。

- **表**：普段はここだけで足りる
  - XY パッド：横が明暗、縦が動静
  - 大つまみ：遠近・重さ・密度・人気（ひとけ）、およびエコーとダブ
  - 下段：各部ごとに、縦フェーダーが音量、つまみが高低
- **ドローン・ノイズ・RES・ARP・声・笛・鐘・場・FX・LFO**：全項目。すべて鳴らしたまま動かせる
- **プリセット**：保存・削除・書き出し・読み込み、乱数のシード
- 上辺：プリセット、切替にかける「モーフ」の秒数、再生

下段の「高低」は部ごとに中身が異なる。

| 部 | 高低の中身 |
|---|---|
| ドローン・RES | 半音刻みで上下二オクターブ。基音はそのままに、その部だけを移す |
| ノイズ | 帯域を移す。低へ回せば高域を、高へ回せば低域を削る |
| ARP | 積層の中心の高さ（55〜3520Hz） |
| 声 | 声の高さ（50〜500Hz） |
| 笛・鐘 | 鳴らす音域の中心。音はその近くの音階音から選ばれる |

パッドと大つまみは**マクロ**である。一つで複数の項目を束ねて動かす。プリセットの値への上乗せとして働き、中央で無変化となる。束の中身は `params.js` の `MACROS` に在る。

つまみは縦に引いて回す。二度叩くと既定値へ戻る。PC では車輪と矢印キーにも応じる。

声・笛・鐘の「間」は沈黙の平均の長さで、約0.25秒から約60秒まで取れる。

プリセットは内蔵28種。眠り・瞑想・環境・実験の四組に分けてある。自作は端末内に保存される。端末間は「書き出し」のリンクで渡す。
タイマーは末尾で音を絞って止まる。画面を消していても効く。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` `style.css` | 画面の外枠 |
| `params.js` | 全パラメーター・音階・内蔵プリセットの定義表 |
| `engine.js` | 発音部（AudioWorklet） |
| `app.js` | 画面の組み立て（つまみ・XY パッド・各面）、プリセット、タイマー |
| `test.html` | 消灯再生試験。画面を消しても鳴り続けるかを確かめた頁 |
| `tools/render.mjs` | **開発用**。発音部をブラウザ抜きで回し、WAV に書き出して音量と処理速度を測る |

## 動かす

静的配信すればよい。

```bash
python -m http.server 8791 --directory .
```

発音部だけを測る：

```bash
node tools/render.mjs 錬鉄 30 out.wav
node tools/render.mjs - 20 out.wav droneLevel=0 voiceLevel=0.8 voiceBreath=1
```
