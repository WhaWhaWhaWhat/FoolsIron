# FoolsIron

瞑想・入眠のためのドローン／ノイズ／合成音声機械。鳴らして、置いておく生成器である。
名は David Rosenboom《Portable Gold and Philosophers' Stones》への敬意による。

Android と Windows の双方で動くよう、依存なしの単一ページ（WebAudio / AudioWorklet）とする。
GitHub Pages で配る： https://whawhawhawhat.github.io/foolsiron/

## 発音部

| 部 | 中身 |
|---|---|
| 持続音 | 基音の16倍音までの格子。各倍音は二声のうなりを持ち、非周期の揺らぎで明滅する。副発振つき |
| 雑音 | 白・桃・茶を連続に渡る。寄せては返す音量の波 |
| 共鳴 | 音階に調律した16の共鳴器。雑音・反復・声が共有して鳴らす |
| 反復 | オクターブ積層の声部（シェパード音）。階段／滑走（Risset グリッサンド）／輪（非通約ループ）の三型 |
| 声 | フォルマント合成による、意味の取れぬ発話。種ごとに語彙を持つ架空の言語を喋る。囁き、詠唱も可 |
| 場 | 八本の遅延線による残響、全体の広がりと漂い、LFO 二基 |

## 操作

- **卓**：各部の音量と、基音・明るさ・揺らぎ・空間・広がり・漂い。普段はここだけで足りる
- 各部の詳細は折り畳みの中にある。すべて鳴らしたまま動かせる
- **プリセット**：内蔵8種。自作は端末内に保存される。端末間は「書き出し」のリンクで渡す
- **移ろい**：プリセットを切り替える際、指定の秒数をかけて渡る
- **種**：反復の輪の構成と、声の言語を決める乱数の種
- **タイマー**：末尾で音を絞って止まる。画面を消していても効く

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` `style.css` | 画面の外枠 |
| `params.js` | 全パラメーター・音階・内蔵プリセットの定義表 |
| `engine.js` | 発音部（AudioWorklet） |
| `app.js` | 画面の組み立て、プリセット、タイマー |
| `test.html` | 消灯再生試験。画面を消しても鳴り続けるかを確かめた頁 |
| `tools/render.mjs` | **開発用**。発音部をブラウザ抜きで回し、WAV に書き出して音量と処理速度を測る |

## 動かす

静的配信すればよい。

```bash
python -m http.server 8791 --directory .
```

発音部だけを測る：

```bash
node tools/render.mjs 錬鉄 30 out.wav
node tools/render.mjs - 20 out.wav droneLevel=0 voiceLevel=0.8 voiceBreath=1
```
