# FoolsIron

瞑想・入眠のためのドローン／ノイズ／合成音声機械。放置して鳴らし続ける生成器として造る。
名は David Rosenboom《Portable Gold and Philosophers' Stones》への敬意による。

Android と Windows の双方で動くよう、依存なしの単一ページ（WebAudio）とする。

## 現状：消灯再生試験

`index.html` は発音機械の本体ではなく、**Android で画面を消しても鳴り続けるか**を確かめる試験ページである。
ここが崩れれば配り方の前提が変わるため、最初に確かめる。

- 仮ドローン：110Hz を基音とする8倍音。各倍音は二声のうなりを持ち、互いに合わぬ周期で明滅する
- 出力経路の切替：`audio` 要素経由（メディア通知あり）／直接出力
- スリープタイマー：音の時計の上に予約するので、裏で JS が間引かれても絞りは効く
- 退避策：画面を点けたまま黒くする暗転
- 記録：消灯から復帰した際、実時間と音の時計の進みを比べて途切れを判じる。記録は端末に残り、次回「前回の記録」で読める

### 試し方

1. GitHub Pages（Settings → Pages → `main`）で配り、Android の Chrome で開く
2. 「audio要素経由」で鳴らし、画面を消して 10〜30 分置く
3. 耳で途切れを確かめ、画面を点けて記録の「復帰」行を読む
4. 途切れたなら「直接出力」、それも駄目なら「暗転」で同じ時間置く

## 予定

- 発音エンジン（AudioWorklet）：倍音格子ドローン、共有共鳴器バンク、ノイズ部
- 反復部：シェパード音階／Risset グリッサンド／非通約ループ
- 声部：意味の取れぬ発話（フォルマント合成、囁き）
- マクロ操作、プリセット（保存・書き出し・緩慢な切替）
